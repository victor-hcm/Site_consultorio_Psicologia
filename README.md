## 🚀 Como Rodar o Projeto Localmente
1. Instale um servidor local (como XAMPP ou WampServer).
2. Clone ou coloque a pasta do projeto dentro do diretório `htdocs` do seu servidor.
3. Importe o arquivo `database.sql` no seu MySQL (via phpMyAdmin).
4. Inicie os serviços Apache e MySQL.
5. Acesse no navegador: `http://localhost/consultorio-psicologia/index.html`
